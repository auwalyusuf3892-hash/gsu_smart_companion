# 💚 GSU Smart Companion (Build for Gombe)

An offline-first, bilingual (English & Hausa) academic companion built for Gombe State University (GSU) students. It combines local machine learning with Gemma 4 AI coaching to help students navigate their academic trajectory even in low-bandwidth or offline campus environments.

## 🚀 Key Features
- **On-Device KNN Trajectory Classifier ($k=4$):** Evaluates local O-Level and UTME datasets using Euclidean distance in under 2ms to predict degree classes (First Class, 2:1, etc.).
- **Gemma 4 Bilingual AI Coaching:** Generates personalized semester action plans and practice quizzes in English or local Hausa language.
- **Instant Lecture Note Quizzer:** Automatically converts uploaded study materials or lecture notes into multiple-choice quiz questions.
- **Edge AI & Snowflake Architecture:** Designed with zero-internet offline fallback for rural campuses and Snowflake Data Cloud SQL export telemetry.
