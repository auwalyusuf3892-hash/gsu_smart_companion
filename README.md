\# GSU Smart Companion (KNN + Gemma 4 Edge AI)



An open-source, offline-first academic companion built for Geeks Open Hack Day Gombe 2026 at Gombe State University (GSU).



\## Challenges Targeted

\- Best Use of Gemma 4: Generates 100-Level semester study plans and converts lecture notes into practice quizzes.

\- Edge AI Challenge (Arduino UNO Q Track): Runs a local K-Nearest Neighbors (KNN, k=4) classifier on-device in under 2ms with an offline Gemma 4 fallback mode for low-connectivity campuses.

\- Best Open-Source AI Project (DigitalOcean): Open-source Flutter application.



\## How It Works

1\. On-Device KNN Predictor (k=4): Calculates Euclidean distance using O-Level \& UTME scores to predict academic trajectory.

2\. Gemma 4 Academic Coach: Turns the prediction into a customized GSU semester study plan.

3\. Instant Exam Quizzer: Generates multiple-choice questions from lecture notes.
